# TypeScript + Express.js Setup — Currency Converter Service

## Overview

TypeScript + Express.js currency converter using **OOP** and **Layered Architecture**. SQLite for rate storage, Docker for running the service.

**Key Features:**

- TypeScript strict typing with modern config
- Express REST API with OOP controllers/services
- Layered Architecture: Controllers → Services → Repositories → Models
- SQLite (`better-sqlite3`) for exchange rates and history
- In-memory cache (Map) + DB fallback
- Nodemon/ts-node for hot reload in development

**Software Architecture: Layered OOP (SOLID-compliant)**

```
┌─────────────────┐
│   Controllers   │  (Handle HTTP requests)
├─────────────────┤
│    Services     │  (Business logic, API aggregation)
├─────────────────┤
│   Repositories  │  (Data access, DB/cache)
├─────────────────┤
│     Models      │  (Types, Interfaces, Entities)
└─────────────────┘
```

## Setup Steps

1. **Initialise project**

   ```bash
   npm init -y
   ```

2. **Set `"type": "module"` in `package.json`**

   Required to align with `"module": "NodeNext"` in `tsconfig.json`:

   ```json
   {
     "type": "module"
   }
   ```

3. **Install packages**

   ```bash
   npm i express cors better-sqlite3 dotenv winston
   npm i -D typescript @types/node @types/express @types/cors @types/better-sqlite3 ts-node nodemon rimraf
   ```

4. **Add scripts to `package.json`**

   ```json
   {
     "scripts": {
       "dev": "nodemon --exec \"node --loader ts-node/esm\" src/index.ts",
       "build": "rimraf dist && tsc",
       "start": "node dist/index.js",
       "clean": "rimraf dist node_modules"
     }
   }
   ```

5. **Create `tsconfig.json`** (see config below)

6. **Create `.env`** in the project root:

   ```env
   NODE_ENV=development
   PORT=3000
   SERVER_URL=http://localhost:3000
   DB_PATH=./data/currency.db
   FIXER_API_KEY=<your_key>
   OPEN_EXCHANGE_APP_ID=<your_key>
   CURRENCY_API_KEY=<your_key>
   ALLOWED_ORIGINS=http://localhost:3000
   ```

7. **Run via Docker** (see `DOCKER_SETUP.md`)

   ```bash
   docker compose up --build -d
   ```

## Database: SQLite

**Why SQLite?**

- No separate server — single file, zero config
- Perfect for rate history (append-only, read-heavy)
- `better-sqlite3` has excellent TypeScript types
- Data persisted via the `sqlite_data` Docker named volume

**Schema:**

```sql
CREATE TABLE exchange_rates (
  id        INTEGER PRIMARY KEY,
  base      TEXT NOT NULL,
  target    TEXT NOT NULL,
  rate      REAL NOT NULL,
  timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
  source    TEXT
);
```

## tsconfig.json

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "outDir": "./dist",
    "rootDir": "./src",
    "resolveJsonModule": true
  },
  "ts-node": {
    "esm": true
  }
}
```

> `"module": "NodeNext"` requires `"type": "module"` in `package.json`. Without it, `npm run build` will fail inside Docker.
